# API-Weather

Приложение для получения текущих данных о погоде через API OpenWeatherMap.

## Описание

Проект использует OpenWeatherMap API для получения информации о погоде по названию города или координатам (широта, долгота).

## Требования

- Python 3.7+
- pip (менеджер пакетов Python)

## Зависимости

```
colorama
requests
python-dotenv
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Установка

1. Клонируйте или загрузите проект
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:
   - **Windows:**
     ```bash
     venv\Scripts\activate
     ```
   - **Linux/Mac:**
     ```bash
     source venv/bin/activate
     ```

4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Создайте файл `.env` в корне проекта и добавьте ваш API ключ:
   ```
   API_KEY=your_openweathermap_api_key
   ```

   Получите API ключ на https://openweathermap.org/api

## Использование

Запустите основную программу:

```bash
python weather.py
```

Программа попросит ввести название города, а затем выведет текущую погоду для этого города.

**Пример:**
```
Введите название города: Москва
Получаем погоду для города: Москва
```

## Функции

### `get_current_weather(city: str=None, lat: float=None, lon: float=None) -> dict`

Получает текущую погоду для города или координат.

**Параметры:**
- `city` (str): Название города
- `lat` (float): Широта координат
- `lon` (float): Долгота координат

**Возвращает:**
- `dict`: Словарь с данными о погоде

### `get_coordinates(city: str) -> tuple`

Получает координаты (широту и долготу) города по его названию.

**Параметры:**
- `city` (str): Название города

**Возвращает:**
- `tuple`: Кортеж (широта, долгота) или None при ошибке

### `get_weather_by_coordinates(latitude: float, longitude: float) -> dict`

Получает данные о погоде по координатам.

**Параметры:**
- `latitude` (float): Широта координат
- `longitude` (float): Долгота координат

**Возвращает:**
- `dict`: Словарь с данными о погоде или None при ошибке

## Решение проблем

### Ошибка: "Не удалось получить данные о погоде"

1. Проверьте, что файл `.env` существует и содержит корректный `API_KEY`
2. Убедитесь, что у вас есть интернет-соединение
3. Проверьте, что название города написано правильно
4. Проверьте лимиты API на сайте OpenWeatherMap

### Ошибка: "API_KEY не найден"

Создайте файл `.env` в корне проекта:
```
API_KEY=your_api_key_here
```
